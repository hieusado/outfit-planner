# Outfit Planner

Outfit Planner is a dark-themed Expo and React Native app for managing outfit combinations, tracking daily wear, and filtering wardrobe items by category or name.

## Features

- View a full outfit list
- Search outfits by name or item
- Filter outfits by category
- Add, edit, and delete outfits
- Log an outfit as worn today
- Browse a detail view for each outfit
- Persistent storage with AsyncStorage for offline-ready behavior
- Mock remote data layer to simulate an API response

## Tech stack

- Expo SDK 51
- React Native
- TypeScript
- Expo Router
- AsyncStorage

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the app:
   ```bash
   npx expo start
   ```

3. Run it on a device or emulator.
